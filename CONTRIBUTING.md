# Contributing

**English** · [简体中文](#简体中文) · [日本語](#日本語) · [Español](#español) · [Português](#português) · [Français](#français) · [Deutsch](#deutsch)

This project is in early development and, for now, is maintained solo until it
matures. **External pull requests are not being accepted yet** — that will change
as the project stabilizes. Bug reports and ideas are welcome via issues. Thank
you for your interest.

---

## 简体中文

本项目处于早期开发阶段，在其成熟到一定程度之前暂由个人维护。**目前尚不接受外部的
拉取请求（PR）** —— 随着项目趋于稳定，这一点会改变。欢迎通过 issue 提交缺陷报告与
想法。感谢你的关注。

## 日本語

本プロジェクトは初期開発中で、ある程度成熟するまでは当面、個人で開発します。
**外部からのプルリクエストは現時点では受け付けていません** — プロジェクトが安定する
につれて変わります。バグ報告やアイデアは issue で歓迎します。ご関心に感謝します。

## Español

Este proyecto está en desarrollo inicial y, por ahora, se mantiene en solitario
hasta que madure. **De momento no se aceptan pull requests externas** — esto
cambiará a medida que el proyecto se estabilice. Los informes de errores y las

## Português

Este projeto está em desenvolvimento inicial e, por enquanto, é mantido
individualmente até amadurecer. **No momento, pull requests externas não são
aceitas** — isso mudará à medida que o projeto se estabilizar. Relatos de bugs e
ideias são bem-vindos via issues. Obrigado pelo interesse.

## Français

Ce projet en est à ses débuts et reste, pour l'instant, maintenu en solo jusqu'à
ce qu'il mûrisse. **Les pull requests externes ne sont pas encore acceptées** —
cela changera à mesure que le projet se stabilisera. Les rapports de bugs et les
idées sont les bienvenus via les issues. Merci de votre intérêt.

## Deutsch

Dieses Projekt steht am Anfang und wird vorerst im Alleingang gepflegt, bis es
reift. **Externe Pull Requests werden derzeit nicht angenommen** — das ändert
sich, sobald das Projekt stabiler wird. Fehlerberichte und Ideen sind über Issues
willkommen. Danke für dein Interesse.
