# 符号なし整数の独立した更新

順序付き解析で、ローカル変数と[整数値引数](configured_integer_parameters.md)の符号なし整数への独立した `n++` / `++n` / `n--` / `--n` を扱う。
forの更新式にも使用できる。型はClangのcanonical typeで確認し、typedefも同様に扱う。
capabilityは `source-unsigned-updates.c.v1`。boolは対象外。

更新を同じストレージへのreadとwriteとして検査する。読み取り専用、寿命終了、
持続借用と競合する更新を拒否し、memoryAccess有効時はアクセス幅・配置も検査する。
状態機械の反復でも更新を通過でき、二重開始や借用終了漏れを継続して検査する。

更新後の正確な値は不明とし、以前のscalar値の事実を消去する。
符号なしのラップアラウンドを単調なカウンタとして扱わず、反復回数や終了性を導出しない。
例えば `for(unsigned i=0;i<4;i++)` は、一般の整数値域を追跡して4回と証明するものではない。
未知条件の各経路を探索するため、値域解析があれば除外できる経路も検査対象に残る。
更新後の添字で容量が証明できなければ未検証にする。

対応範囲は、式の結果を使用しない、直接の変数名への更新。
符号付き整数、ポインタ更新、間接参照、条件式/戻り値等に埋め込んだ更新、
volatile/atomic、マクロ経由の更新は未対応を維持する。
グローバルなど、起源未確定のストレージは未知として拒否する。
符号付きオーバーフローや一般の整数演算を保証する機能ではない。

回帰: `python3 tests/run_tests_unsigned_updates.py`。
`tests/c/t265_unsigned_updates.c` とJSONは独自作成。外部コード・仕様・依存追加なし。

## += / -=（2026-09-20）

`source-unsigned-compound.c.v1` は独立した符号なし整数の `+=` / `-=` に対応する。
左辺は直接の変数名でunsigned int以上の型、右辺は左辺以下のsizeof幅を持つ整数型に限定する。
これにより当該加減算が符号なし演算になる範囲を扱う。狭い左辺、幅の広い右辺、
符号付き左辺、浮動小数点、他の複合演算子は未対応。

左辺のreadと右辺のreadを検査した後、左辺のwriteを検査する。右辺でAPIを呼ぶ形式や
副作用を含む形式を受理せず、操作順序を勝手に仮定しない。
配列を右辺に使う場合はmemoryAccessによる範囲/配置検査を適用し、排他的借用との
競合も検査する。更新後の数値は不明とし、正確な回数・値域を保証しない。

回帰: `python3 tests/run_tests_unsigned_compound.py`。
`tests/c/t268_unsigned_compound.c` とJSONは独自作成。外部コード・仕様・依存追加なし。
